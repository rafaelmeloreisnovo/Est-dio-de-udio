# Rafaelia Audio Studio — Public Product Brief

Rafaelia Audio Studio is a mobile audio workstation and measurement research platform for Android. It combines raw recording, narration workflows, fixed-point DSP, relative electroacoustic capture, session/calibration containers and on-device evidence generation.

## Highlights

- 48 kHz PCM capture and source preservation;
- professional workspaces for REC, EDIT, CAL, SPEC, ROOM, VOICE, MASTER and EXPORT;
- authorial freestanding C signal cores;
- ARMv7 and AArch64 validation gates;
- ZRF session container and CFR calibration container;
- relative speaker-room-microphone sweep capture;
- evidence button that records installed APK SHA-256, build provenance and device capabilities;
- accelerometer μ∆ observation for vibration/motion context.

## Scientific boundary

The project distinguishes implementation from evidence. Absolute SPL, standards conformance, room metrics and fault diagnosis are only claimed when their required references and tests exist.
