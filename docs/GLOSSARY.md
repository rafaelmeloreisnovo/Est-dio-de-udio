# Glossary

- **ABI** — externally visible binary interface.
- **CFR** — project-local calibration/response container.
- **ZRF** — project-local session/wave/matrix container.
- **freestanding core** — C code compiled without hosted runtime assumptions.
- **JNI** — Android native bridge, a platform edge.
- **μ∆** — micro-delta step; a local change operator.
- **Δa** — acceleration difference between adjacent sensor samples.
- **relative calibration** — measurement of a path without an absolute SPL reference.
- **absolute SPL** — sound-pressure-level measurement requiring a physical reference/calibration.
- **receipt** — append-only record of an executed evidence state.
- **TOKEN_VAZIO** — explicitly unknown/unavailable evidence; not zero.
- **OBSERVED_UNPROMOTED** — observed data that has not crossed a validation gate.
- **PASS** — a defined gate executed successfully.
