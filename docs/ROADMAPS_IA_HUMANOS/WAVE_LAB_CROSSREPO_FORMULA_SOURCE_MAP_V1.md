- RLL root files `Matemática.md`, `MathRaf.md`, `Numprimod.md` are **separate source documents**, not substitutes for curated RLL registry. `MathRaf.md` explicitly corrects a mistaken universal real period-42 claim; fixed-point cycle proof requires the exact integer implementation.
- teoremas/`docs/rafaelia/350-formulas-mvps.md` has **350 numbered headings containing repeated generic MVP text**, not 350 distinct mathematical expressions. Record `COUNT_LABELS=350`, `COUNT_UNIQUE_FORMULAS=TOKEN_VAZIO` for this file.
- RLL `artifacts/formulas/SESSION_FORMULAS_53_INTEGRATION_V1.json` is a pointer to Mapa's 53-entry canonical registry; RLL binds only selected IDs, no full duplicate inventory.
- RLL `docs/RLL_NOVOEXPORT_FORMULA_ATLAS.md` reports large candidate occurrence counts from external corpus, *not validated equations*.
- The claimed “~609 formulas” is `TOKEN_VAZIO_UNRECONCILED_CANONICAL_COUNT` until formula IDs, sources and deduplication equivalences are verified. 168, 251, 350, 420 and 53 have **different unit types** and MUST NOT be added.
